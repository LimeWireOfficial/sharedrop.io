# sharedrop.io

Source code of the client served at [sharedrop.io](https://sharedrop.io) — exactly the files the site serves, updated automatically on every deploy.

ShareDrop sends files directly between devices with WebRTC. Files picked for a direct transfer travel peer-to-peer and do not pass through our servers. Optional cloud links (for devices that are not online at the same time) are provided by [LimeWire](https://limewire.com).

## Origins

sharedrop.io is based on [ShareDrop](https://github.com/ShareDropio/sharedrop) by Szymon Nowak and contributors, licensed under the MIT License. The original copyright notice is preserved — see [LICENSE](LICENSE).

## Running your own copy

The pairing (signaling) server is not part of this repository and only accepts connections from sharedrop.io. To run your own copy you need your own signaling server.
